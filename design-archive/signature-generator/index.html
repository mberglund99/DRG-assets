Add it to Outlook on the web
  1. Click Copy signature above.
  2. In Outlook, open Settings (gear icon) → Accounts → Signatures.
  3. Click + New signature, name it, and paste (Ctrl/Cmd + V) into the editor.
  4. Set it as the default for new messages and replies, then Save.
